# HUD 实测库

**唯一权威的速度换算依据。** 静态推算一律不算数——
物理 `ground_speed` 与比赛中 HUD 显示速度的关系，**只能由实测确定**。

---

## 铁律

1. **只记录比赛里 HUD 实际读到的数字。** 车库面板值属于 business 库，不入此表。
2. 每条必须注明**测量条件**：是否满改、氮气状态、路段（直线/弯道）。
3. **面板值另存一列做对照，但不参与拟合。**
4. 数据点 < 5 个时，不得声称换算关系已确定。

## 为什么立这个库

早期曾担心塞纳 360.8 / 杰AB 541 是车库面板值而非 HUD（360.8 与塞纳
business 库 top_speed 接近），一度把两点标为存疑。
**车主已确认：给出的数字全部是比赛 HUD 实读。** 四点恢复为确认点。

教训不变：**记录时必须当场注明来源**，事后靠数值形态去猜必然出错。

## 数据表

见 `hud-data.json`。字段说明：

| 字段 | 含义 |
|---|---|
| `car` | 车名（与 CarDef 一致） |
| `physical` | CarPhysics `idx23`（ground_speed 满级值） |
| `hud` | **比赛中 HUD 实测最高速** |
| `panel` | 车库面板极速（仅作对照，不参与拟合） |
| `condition` | 测量条件 |
| `confirmed` | 车主是否明确说明"比赛里看到的" |
| `source` | 数据来源 |

## 当前状态

**已确认 HUD 实测点：4 台不同的车，4 个不同物理值，覆盖 218.5 ~ 357。**

```
HUD = 2.1483 × 物理 − 211.56        R² = 0.9997   (n = 4)
```

| 车 | 物理 | 实测 HUD | 预测 | 残差 |
|---|---:|---:|---:|---:|
| 宝马 Z4（原厂） | 218.5 | 260.0 | 257.9 | +2.1 |
| 麦克拉伦 塞纳（满改） | 268.0 | 360.8 | 364.2 | −3.4 |
| 柯尼塞格 杰AB | 350.0 | 541.0 | 540.4 | +0.6 |
| 宝马 Z4（v2 改造） | 357.0 | 556.0 | 555.4 | +0.6 |

**四台完全不同的车落在同一条直线上，残差 ±3.4** —— 这不是两点共线的假象，
是真关系。工具仍按 <5 点报警告，但可以按此设计。

**反查常用值**

| 想要 HUD | 物理 ground_speed |
|---:|---:|
| 300 | 238.1 |
| 330 | 252.1 |
| **350** | **261.4** |
| 400 | 284.7 |
| 450 | 308.0 |

**注意**：截距 −211.56 意味着这条线**只在实测区间 218~357 内可信**，
不要外推到低速段。

## 待补测清单（优先级从高到低）

1. **同一台车多个物理值** —— 最有价值，能直接给出斜率
2. **不同物理值的原厂车** —— 覆盖低/中/高三档
3. **同车、氮气开/关两种状态** —— 分离氮气加成的贡献

## 用法

```bash
python ../tools/hud.py add --car "BMW Z4" --physical 357 --hud 556 --condition "改造版直线"
python ../tools/hud.py fit          # 拟合并报告置信度
python ../tools/hud.py predict 260  # 反查：想要 HUD 260 该填多少物理值
```
