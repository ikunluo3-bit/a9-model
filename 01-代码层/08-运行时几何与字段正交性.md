## 1. 半径：双约束模型（车主实测确立）

```
实际过弯半径 ≈ max( 几何项 , 滑移极限项 )
几何项   = v / ω          ω 由转向表给出，表参数来自 锐度 idx19/21
滑移极限项 = v² / (μ·g)    μ 来自抓地 idx78/79
```

- **低速/中速弯：几何项主导** → 锐度是半径的唯一实用旋钮
- **高速大弯：极限项反超**（v² 涨得快）→ 此时才轮到抓地说话
- 两项谁主导取决于当前车速，同一台车两种状态都存在

### 实测证据链

| 实验 | 结果 | 出处 |
|---|---|---|
| 女武神→科迈罗 加抓地 1.53×，极速 ×1.22 | 半径体感**原地踏步**（几何项主导，抓地不在其公式里） | 07 §7 |
| AMG→Z4 只动锐度 58000→98900（×1.71），抓地原厂 | 半径**明显变小** + 漂移损速下降 | 11 |
| 锐度只 +12%（65000） | 体感无变化（被噪声淹没） | 11 |
| v2/v3 批：极速 ×1.6 而抓地 ×2 | 高速弯半径变大（极限项接管：357²/1.153） | 05 |

**推论**：调半径先加锐度；锐度到位还嫌大（高速弯），才考虑抓地/压极速。

## 3. 抬轮的真实结构（10 号文档闭合后的定稿）

```
抬轮/侧倾观感 = f( 下压力 idx30/31 [主控], 悬挂行程 16–19 [侧倾范围], 侧向力大小 [激励] )
```

- 下压力越高越压得住：P1 550 贴地 / McMurtry 845 / Devel 1150 顶格
- 行程决定车身可动范围：AMG 0.08 是 P1 0.01 的 8 倍——压重心救不了侧倾
- 阻尼只调运动快慢；**范围由行程决定**

## 4. 氮气系统速查（1 号文档闭合，全库 290 台验证）

```
每档 4 参数：A(未解) / drain 消耗(越小越省) / spd 加成(物理速度) / hold 维持(硬拐不掉速能力)
四档：单喷 < 橙喷(双击) < 蓝喷(完美) < 紫喷(脉冲)
设计规律（零例外）：维持 蓝 > 单 > 橙；紫喷维持≈0 纯爆发
```

改装手法：
- `--nitro-boost x`：四档加成同乘（物理速度单位，HUD 增量 ≈ 增量 ×2.15）
- `--nitro-drain x`：四档消耗同乘（0.5 = 单口时长 ×2）
- `--purple-drain x`：只动紫喷（Biome 105→35 那种单点手术）

## 5. 被推翻的公式（考古区，勿复活）

| 废弃结论 | 死因 |
|---|---|
| 抬轮 = 抓地 × \|重心\| ÷ 前轮距 | 相关能排序原厂车，不能预测改装行为；降重心 28% 实测零缓解（10 §1）。保留为"原厂车经验排序指标"，禁止用于改装 |
| 加抓地→半径变小（单约束 R=v²/μ） | 几何项主导时抓地无效；加抓地 1.53× 半径纹丝不动（07 §7） |
| 锐度≈转向响应速度、不管半径（面板相关 0.2864 推断） | 单变量 A/B 直接证伪：锐度 +70% 半径显著变小（11）。**相关性弱≠无因果**，与下压力当年被错杀同款坑 |
| 抬轮吃前轴侧向力→推头（触地门控机制） | 归因错误：算术（基准选错）能解释的现象不需要机制背锅（07 §7）。门控本身存在（0x584bb74），但在 0.08 量级是否触发未验证 |
| idx30/31 与抓地相关弱→不是下压力 | 判别分析推翻（10）。方法论：**按目标现象分组做判别，别用跨字段相关性定性** |
