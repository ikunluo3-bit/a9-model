# 活动券票机制（TLE / Gauntlet）

配套阅读：[`08-燃油机制.md`](08-燃油机制.md)（车辆油量 = Maintenance）。

**先排除一个误解**：「每日赛事」的券票**不属于** `*Daily*` 那一套。
so 里 141 个 `*Daily*` 标识符全是 **每日任务 / 每日奖励 / 每日兑换券 / 每日 XP 上限**，
跟券票没关系。**券票属于 TLE（Time Limited Event，限时赛事）体系。**

---

## 1. 四种独立的限时资源

| 资源 | 作用域 | 状态存放 |
|---|---|---|
| 车辆油量 Maintenance | **每辆车** | 车记录里的 13 字节块 |
| **TLE 券票** | **全局** | 档案 `ticketBalance` |
| Gauntlet 券票 | 全局，独立计数 | `maxTickets` / `ticketPurchasesLeft` |
| 每日兑换券 | 全局 | `oldDailyVouchers` / `nextAvailableDailyVouchersTimePoint` |

四套**互不共用**，各有各的计时器。

## 2. TLE 券票的完整字段

档案里 `ticketBalance` 与 `lastTicketRefilledTime` 紧挨着
`tlEventDataById` / `topUpEventDataById` / `specialEventDataById` / `walletEventId`
—— 确认是**全局玩家状态**。

补充相关的结算载荷：

```
optNextAvailableTLERefillTimePoint   下一次免费补充可用的时间点（可选=当前就能补）
refillsAvailable                     剩余免费补充次数
oldTicketBalance / newTicketBalance  补充前后的券票数
lastTicketRefilledTime               上次补充时间
```

动作：`TLEventRefillTickets`（Request/Result）。
通行证加成：`STR_SEASON_PASS_BENEFITS_TLE_EXTRA_REFILLS`（含 VIP/传奇版）。

**关键点**：`optNextAvailableTLERefillTimePoint` 是**服务端算好推下来的时间点**，
客户端只负责画 `tickets_refill_timer/timer` 倒计时。

## 3. Gauntlet 券票（另一套）

```
maxTickets            上限
ticketPurchasesLeft   还能买几次（有次数上限）
GauntletBuyTicket     购买动作
refill_tokens / refill_vouchers   两种货币各一个按钮
```

文案：`STR_GAUNTLET_TICKETS_PURCHASE_TOCKENS_BTN` / `_VOUCHERS_BTN` /
`STR_GAUNTLET_TICKETS_PURCHASE_CANCELLED`。

错误码：`NotEnoughTickets`、`MaxTicketsPurchasedReached`、`TicketsAreFull`。

## 4. 协议里带作弊动作

```
TLETicketsCheat / TLETicketsCheatRequest / TLETicketsCheatResult
GauntletSetTicketsCheat / GauntletSetTicketsCheatRequest / ...Result
settickets
```

**这是官方留在协议里的开发指令**，服务端认就能直接设券票数。
对私服来说这是最干净的入口 —— 不用碰客户端。

（同类的还有 `forceDefeatCheat`、`cheatTracks`、`cheatDivision`、
`CompleteCareerSeasonCheat`、`GainEventFlagCheat`、`UnlockAllChaptersCheat`、
`UnlockAllSeasonsCheat`、`FreeTemporaryMaxOutCar`。）

## 5. 配置一个字节都不在 APK 里

- 所有 gdb 里**零个** `ticket` / `maintenance` 配置串
- `EventPayload.gdb` 只有 **1,045 字节**，无券票配置
- 档案里有 `eventDBRevision` —— **活动库是服务端按版本号推下来的**

所以补充间隔、券票上限、购买价格**全部服务端决定**，改 APK 无效。

## 6. 当前私服状态

`server/` 里搜 `ticket` 只命中 **control plane 的身份票**
（`IDENTITY_TICKET_RE = ^a9i_...`、`ticketHash`、`ticketRotatedAt`），
与活动券票无关 —— **私服没有实现券票逻辑**。

想改，两条路：

1. **实现 `TLETicketsCheat` / `GauntletSetTicketsCheat`** 的响应 —— 官方留的口子，最干净
2. **直接写档案** —— 但 `ticketBalance` 在玩家档案的全局段，
   不像油量那样已经有 `account_store.py` 的解析器覆盖，得先定位偏移
