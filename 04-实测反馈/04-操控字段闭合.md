# 操控字段闭合：idx 76 / 77

**由车主一句话点破**："操控最大的就是管这个漂移和半径"，
并给出定位方法："找操控最低且低等级的车，跟塞纳一比就明白了"。

---

## 0. 补充闭合（`pairscan.py`）：76/77 不是两个字段，是**一对升级值**

`idx76 = 零级值，idx77 = 满级值`。证据：

| 判据 | 结果 |
|---|---|
| 全库 295 台 `76 <= 77` | **295/295** |
| 其中 `76 < 77` | 293/295 |
| 比值中位 | 0.560（与 `14/16`、`19/21` 的 0.500 同档） |
| 开发用参考车 Fastest Car / Slowest Car | **均为 (0.0, 1.0)** —— 满量程 |

**这解释了旧结论里说不通的地方**：
"`77` 相关 0.7985 而 `76` 只有 0.6501，双变量回归里 76 系数仅 0.06" ——
不是因为 76 次要，而是因为**面板操控本来就是按满级算的**，
77 才是面板对应的那一端，76 是同一字段的另一端。

**实践后果**：满改锁必须包含 `(76,77)`。
早期的 16 对里漏了它 —— 意味着**操控仍随车库等级插值，没被锁死**。
现已补入 `transplant.py` 的 `PAIRS`。

尚未定性的同类候选：`(5,6)` 全库 295/295 一致、`(30,31)` 291/295。
两者方向一致但语义未知，**暂不锁**。

---

## 1. 结论

**`idx 77` 是操控字段的满级值**，`idx 76` 是它的零级值。
它同时决定**漂移掉速**与**过弯半径**。

```
面板操控 ≈ 54.63 × idx77 + 38.80          R² = 0.638   (n = 162)
```

| 字段 | 与面板操控相关 |
|---|---:|
| **idx 77** | **+0.7985** |
| **idx 76** | **+0.6501** |
| 转向锐度 idx19 | +0.2864 |
| idx 26 | +0.1561 |
| idx 24 | +0.1062 |
| 抓地 idx79 | −0.2697 |
| 极速 idx23 | −0.2780 |

**0.80 的相关度是转向锐度（0.29）的近三倍。**
双变量回归中 idx76 的系数仅 0.06 —— **77 主导，76 几乎不独立贡献**。

## 2. 定位过程（差分法）

按车主给的方法，取面板操控两个极端：

| 车 | 面板操控 | rank |
|---|---:|---:|
| Dodge Challenger 392 HEMI Scat Pack | **41.67**（近垫底） | 2152（低等级） |
| McLaren Senna | **104.90**（全库最高） | 4407 |

两车 CarPhysics 全字段差分，按标准差归一后排序：

| idx | Challenger | 塞纳 | 差距 |
|---:|---:|---:|---:|
| **77** | 0.30 | **1.00** | **+3.21σ** |
| 26 | 200 | 8 | −3.19σ |
| 24 | 300 | 108 | −3.02σ |
| **76** | 0.205 | **0.60** | **+2.88σ** |
| … | | | |
| 转向锐度 19/21 | 18650 | 26250 | +1.25σ（仅第 13 位） |

`24/26` 在差分中同样显著，但全库相关仅 0.11/0.16 —— **是这两台车的偶然差异，不是操控字段**。

## 3. 必须更正的旧结论

> 早前记载：**"塞纳 idx76/77 = 0.6/1.0 处于全车最差档，若是阻力类参数，
> 塞纳原厂手感应偏钝"** —— **完全说反了。**

真相是：

- `76/77` 与极速负相关（−0.49 / −0.52）不是缺陷，**是设计上的取舍**：
  **要操控就得让极速**
- 塞纳 `0.60 / 1.00` 是全库最高，**正是它面板操控 104.90 全场第一的原因**
- 杰AB `0.09 / 0.16` 换来的是极速 350

**这条错误持续了很久，直到车主用"操控管漂移和半径"一句话点破。**

## 4. 面板操控 ≠ 物理操控

**普通版 LaFerrari 与 LaFerrari Aperta 的 `76/77` 完全相同（0.450 / 0.730），
但面板操控 43.70 vs 85.11。** 差距来自升级曲线（business 侧），非物理。

因此：

- **改 `76/77` 改变实际手感，不改变车库显示的数字**
- 车主实测参照：370Z 面板操控 82「开起来挺不错」——
  查证其 `idx77` 原厂即为 **1.00**（与塞纳同为最高档）。
  **面板 82 只是账面，物理操控本就是顶级。**
