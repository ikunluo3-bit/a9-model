# 转向锐度定档：A/B 实验（AMG One → Z4）

**一次实验钉死三件事**：乱抬轮的根因、锐度-半径的剂量关系、漂移损速与锐度的联动。

> 后续泛化验证：本结论已推广到全车队——女武神系 62000/80000、AMG 系 98900、
> 狼崽/电莲花 60000、Divo 68000，锐度档位与体感半径全程单调对应，无一反例。
> 车队清单见 [`12-车队改装总账.md`](12-车队改装总账.md)；
> 机制模型见 [`01-代码层/08-运行时几何与字段正交性.md`](../01-代码层/08-运行时几何与字段正交性.md)。

---

## 1. A/B 设计（车主提出，变量隔离）

只保留三个增益（极速 / 加速 / 氮气省耗）+ **一个**物理变量（锐度），
其余全部 AMG One 原厂：抓地 0.8233 / 操控 0.67 / 重心 −0.135 /
下压力 530 / 悬挂行程 0.04–0.08。

| 版本 | 相对上一版装机的差异 | 车主实测 |
|---|---|---|
| 上一版装机 | grip 1.0231 + 重心 −0.122 + 锐度 58000 | 半径小但**乱抬轮、悬挂异常高** |
| A：`ab-steer65000` | 锐度 65000（+12%），其余全回原厂 | 抬轮/悬挂**完全恢复**；半径改善不明显 |
| B：`ab-steer-max` | 锐度 98900（+70%，Devel Sixteen 顶格） | **半径明显变小，原厂手感好开，漂移损速更少** |

## 2. 结论一：乱抬轮的根因是微调组，不是锐度

恢复原厂物理后「抬轮乱跳」「悬挂异常高」**同时消失**——
元凶锁定为 grip 1.0231（侧向力 +24%）+ 重心 −0.122（比原厂高 10%）那组微调。

与 `10-下压力字段闭合.md` 的模型一致：AMG 原厂下压力 530 + 原厂行程
完全管得住原厂抓地；侧向力一旦超出这套配平，压不住。

## 3. 结论二：锐度的剂量——+12% 不够，+70% 立竿见影

- 58000 → 65000（×1.12）：**体感无变化**，被噪声淹没
- 58000 → 98900（×1.705）：**半径明显变小**

> 教训：验证「某变量是否起作用」时，一步跨到全库顶格值。
> 小步试探（+10% 量级）得出的「无效」结论不可靠。

至此锐度 = 半径主控的第四次实测确认（前三次见 `02-抬轮公式闭合.md` 补篇），
且这次是**单变量**证据——前三次是原厂车横比，这次是同一台车只动锐度。

## 4. 结论三（新发现）：锐度拉满后漂移损速下降

车主原话：「同样角度漂移损速变得更少」。

**机制（假设，未单独验证）**：锐度大 → 同速度下角速度 ω 大 →
过同样的弯所需的车身滑移角更小 → 滑移浅 → 能量损失少 → 出弯速度高。
即锐度不只缩半径，还**摊薄了漂移的成本**。

另一种可能：漂移损速公式直接含 ω / 锐度项。
两者都能解释现象，未做判别；下次动锐度时顺带观察即可。

## 5. 最终配置（`ab-steer-max`，已装机）

| 项 | Z4 原厂 | AMG One 原厂 | **最终** |
|---|---:|---:|---:|
| 极速 | 218.5 | 277.3 | **285** |
| 加速 | 2.057 | 2.443 | **2.932** |
| 转向锐度 | 26800 | 58000 | **98900**（全库顶格） |
| 氮气消耗 | — | — | **×0.6** |
| 抓地 | 0.580 | 0.8233 | 0.8233（原厂） |
| 操控 76/77 | 0.30/0.42 | 0.35/0.67 | 0.67（原厂满级） |
| 下压力 30/31 | 250/340 | 400/530 | 530（原厂） |
| 重心 | −0.160 | −0.135 | −0.135（原厂） |
| 悬挂行程 | 0.03–0.06 | 0.04–0.08 | 0.04–0.08（原厂） |

```bash
python tools/carswap.py \
    --swap "Mercedes_AMG_One>BMW Z4 LCI E89" \
        --top-speed 285 --accel 2.932 --nitro-drain 0.6 --steer 98900 \
    --apply
./tools/build.sh ab-steer-max --tuned ".../tuned-carswap" \
    --files CarPhysics.gdb CarChassis.gdb CarDef.gdb
```

**原则**：增益只动「动力三件套 + 锐度」四个与操控配平无关的量，
侧向力链（抓地/下压力/悬挂/重心/操控）整套用供体原厂配平，不拆开抄。
