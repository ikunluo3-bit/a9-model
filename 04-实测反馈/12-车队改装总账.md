# 车队改装总账（2026-08-28 更新，21 台现役）

**本文档是车队现状的唯一权威快照。** 接手人从这里查每台车改了什么；
想加车/回滚/微调，直接在 `carswap.py --swap` 命令里增删对应行重跑即可。

> **⚠️ 事故记录（2026-08-28）**：单车改动直接跑 `carswap.py --apply` 并装机——
> carswap 从原始库全量重算，输出里只有那一条 swap，20 台车队全部回原厂。
> 从此加车/改车/回滚**只走 `fleet.py`**（add/set/donor/remove → build → install），
> `fleet-plan.json` 是唯一事实源。另见 README 陷阱 11（UI 名≠库内名，改错车）与陷阱 12。
> 目标车核对双保险：`index6.py` 解析名 + 性能分上限（如 SRT8=1405，392 HEMI=2152）。

> **日常改用 [`tools/fleet.py`](../tools/fleet.py) + 根目录 `fleet-plan.json`**（2026-08-27 起）：
> 计划文件与下面的命令内容一致，`fleet.py add/set/donor/remove/build/install`
> 读写计划文件并从原始库全量重算，效果等价于手敲下述长命令。
> 改了车队之后记得同步更新本文件对应条目。

## 五、调参原则（本车队确立，详见 08 文档）

1. **可动四件套**：极速 / 加速 / 转向锐度 / 氮气（加成+消耗）
2. **不可拆抄**：抓地 / 下压力 / 悬挂行程 / 重心 / 操控 —— 供体原厂配平整体保留
   （拆抄 = 乱抬轮 + 悬挂异常，06/11 两轮实测证伪）
3. **锐度是几何半径唯一主控**：62000 柔 / 80000 锐 / 98900 顶格，车队内三档日常使用
4. **满改锁默认开**；面板（business）永远不动
5. 验证变量有效性：一步跨全库顶格值，小步（+10%）得出的"无效"不可信
