# 氮气四级 · 实测手感 ↔ gdb 字段（已闭合）

来源：车主实测口述 + CarPhysics 290 台车全量验证。

## 实测描述

| 档位 | 手感 |
|---|---|
| **单喷** | 勉强维持氮气极速；硬拐会掉速 |
| **橙喷**（归属待定） | 加速明显很强，空中收益大；消耗速度快 |
| **蓝喷**（= 完美氮气 PerfectNitro） | **维持速度能力最强，硬拐不掉速、能维持氮气极速**；加速不如橙喷；转向比橙喷软；消耗也慢 |
| **紫喷**（脉冲） | 加速最快，消耗最快 |

## gdb 块结构

每档 8 个 float，起点 32 / 40 / 48 / 56：

```
[base+0] A_lo   [base+1] A_hi      未解
[base+2] drain_lo [base+3] drain_hi  氮气消耗率
[base+4] spd_lo   [base+5] spd_hi    速度加成 (km/h)
[base+6] D_lo     [base+7] D_hi      ★ 维持能力
```

## 塞纳实值

| 档位 | 块起点 | drain lo/hi | spd lo/hi | **维持 lo/hi** |
|---|---:|---|---|---|
| 单喷 | 32 | 19.50 / 10.50 | 3.800 / 4.121 | **1200 / 1600** |
| 橙喷（待定） | 40 | 39.00 / 21.00 | 11.400 / 12.364 | **700 / 950** |
| 蓝喷=完美氮气 | 48 | 29.25 / 15.75 | 7.600 / 8.243 | **4000 / 5000** |
| 紫喷 | 56 | 52.00 / 28.00 | 15.200 / 16.486 | **500 / 0** |

## 全车验证（n = 290）

| 命题 | 满足车数 |
|---|---:|
| 消耗 单 < 蓝 < 橙 < 紫 | 287 / 290 |
| 加成 单 < 蓝 < 橙 < 紫 | 288 / 290 |
| **维持 蓝 > 单 > 橙** | **290 / 290** |
| **维持 蓝 > 橙** | **290 / 290** |

全车中位数：

| 档位 | drain_lo | spd_lo | **维持_lo** |
|---|---:|---:|---:|
| 单喷 | 22.50 | 3.714 | 1317.5 |
| 橙喷 | 45.00 | 11.143 | 850.0 |
| 蓝喷 | 33.75 | 7.429 | **4300.0** |
| 紫喷 | 60.00 | 14.857 | 500.0 |

## 结论

**`[base+6]/[base+7]` = 维持能力（抗掉速）**，语义由实测闭合：

- 蓝喷该值全车最大 → "维持速度能力最强、硬拐不掉速"
- 橙喷该值全车最小 → "加速强但消耗快"，硬拐掉速
- 紫喷该值近零（塞纳 500/0）→ 纯爆发不维持

排序在 290 台车上零例外，是设计意图而非巧合。

**仍未解：** `A_lo/A_hi`（全车 0.01–0.05，塞纳 0.03）。

## 与塞纳改动的关系

那次改动只把 8 个 **drain** 值除以 1.2（延长时长），
**spd 和维持值一个字节没动**。所以：

- 氮气加成仍是原厂 16.486 km/h（对上实测"只有 20 公里左右"）
- 四档的维持特性关系未被破坏

## 盲测验证：Mercedes Benz Concept Silver Lightning 2011（银色闪电，R 级）

车主仅凭手感给出两个特征，事先未看任何数据：

> "蓝喷时间明显很长，而且极速更高"

查证结果（记录 0x1A71C）：

| 字段 | 值 | 全车百分位 | 塞纳原厂对照 |
|---|---:|---:|---:|
| **蓝喷 消耗_lo** | **18.00** | **1%**（全车第 3 低） | 29.25 |
| **ground_speed_hi** | **310** | **90%**（全车第 24 高） | 268 |
| 蓝喷 加成_lo | 9.00 | 99% | 7.60 |
| 蓝喷 维持_lo | 7000 | 92% | 4000 |
| tyre_force_hi | 0.9586 | 91% | 0.7848 |
| accel_hi | 2.377 | 34% | 2.414 |

面板：rank 5344 / 极速 446.0（塞纳 4407 / 360.8）

全车分布对照：蓝喷消耗 min 9.00 / 中位 33.75 / max 54.00 —— 银色闪电 18.00 只有中位数的一半。

**结论：两个手感词各自命中一个极值字段，且方向完全正确。**
这台车是"蓝喷特化"设计：蓝喷的消耗、加成、维持三项同时处于全车顶部，
而加速度只有 34 百分位——它不靠加速取胜，靠蓝喷的持续输出。

此例可作为字段语义正确性的独立佐证：
判读方在给出数据前不知道车主会说什么，车主在给出手感时也不知道字段值。
