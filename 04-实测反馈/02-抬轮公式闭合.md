## 1. 关键突破：找到 CarChassis.gdb

抬轮的物理公式是

```
载荷转移 ∝ 侧向力 × 重心高度 ÷ 轮距
```

其中**侧向力**来自 `CarPhysics.gdb` 的 `tyre_force`，

## 3. 塞纳改动的定量后果

```
原厂  0.785 × 0.160 / 1.626 = 0.0772   （全车中位偏下）
改后  1.962 × 0.160 / 1.626 = 0.1931   （全车榜首 0.1216 的 1.6 倍）
```

**改动把塞纳推到了全游戏从未存在过的载荷转移区间**，
这是抬轮行为异常的定量原因。重心和轮距一个字节没改，全部来自抓地力 ×2.5。

## 4. 被证伪的中间假设（勿重走）

| 假设 | 证伪方式 |
|---|---|
| `idx24/26` 是抬轮倾向 | Fordzilla P1 与杰AB 的 24/26 完全相同（108/8），但一个零抬轮一个最高 |
| `idx30/31` 是下压力 | 全车与抓地(−0.13)、极速(−0.12)几乎不相关；高值车里混有 GT-R Nismo、Panamera 等普通跑车 |
| 电动车（452B）布局与普通车不同 | 用氮气块特征定位，452/468/444/460B 的 **shift 均为 0**；只有 436B 是 +2、476B 是 +12 |

## 5. 仍未闭合

# 补：过弯半径的定位（高置信候选）

## 结论

**`idx 19 / idx 21` 是过弯半径的决定字段，值越大 → 半径越小（转向越急）。**

## 三条独立证据

### 1. 车主排序唯一匹配

在 63 个随车变化的字段中，**只有这一对**满足车主给出的半径排序：

| 车 | idx19 | idx21 | 车主描述 |
|---|---:|---:|---|
| **F5R** | **28250** | **56500** | **半径又变小了（最小）** |
| Venom(S) | 25600 | 51200 | 半径小很多 |
| Fordzilla P1 | 24280 | 48560 | 半径也很优秀 |
| **杰AB** | **21000** | **42000** | **半径一般还行（最大）** |

反向排序（值小=半径小）在 63 个字段里 **0 个匹配**。

### 2. 结构与代码吻合

代码侧已确定转向半径区间是**一对 (lo, hi)**：

```
0x58674cc:
    s8 = decode(baseA + 0x18)      # 半径区间 lo  → 结构字段 #2
    s0 = decode(baseB + 0x24)      # 半径区间 hi  → 结构字段 #3
    [x20] = (s8, s0)
配套: 0x5867474 → +0x30 (#4) 速度区间；0x5867430 角度；0x5867428 base
消费者: 0x35cd028 转向表构建（30 点，10→500 km/h，sincos 求角速度）
写入: component + 0x2168
```

而 `idx21 = 2 × idx19` **精确成立**，正是一对 (lo, hi) 的形态。

### 3. 与面板操控的相关方向（n = 185）

| 量 | 与面板 handling 相关 |
|---|---:|
| **idx19 / idx21** | **+0.279** |
| 抓地 idx79 | −0.220 |
| ground_speed idx23 | −0.239 |

**idx19/21 是唯一正相关项。** 相关值不高属预期——面板 handling 属 business
独立数值体系，本就不直接驱动物理。

## 置信度与保留

- **两端极值（F5R 最小半径 / 杰AB 最大半径）完全对上**，这是最强的一条。
- 中间两台（FP1 24280 < Venom 25600）意味着 FP1 半径应略大于 Venom，
  而车主对二者的描述是"优秀"与"小很多"，**孰小未明确**，无法据此证伪或确认。
- `idx14/16` 与 `idx19/21` 互相关 **0.9286**，两组极像前/后同类参数
  （疑似前/后悬挂刚度或前/后转向刚度）。**若 19/21 是后轴，14/16 应为前轴**，
  但尚未分离验证。

**建议的判决性实验**：找两台 `idx19` 差距大、而抓地与极速都接近的车对比半径。
