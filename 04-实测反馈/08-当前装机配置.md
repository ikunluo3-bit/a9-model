# 当前装机配置（`A9-ab-steer-max`）

一次替换两台车，互不影响。构建后已跑崩溃复现，未崩。
Z4 的定档过程（A/B 实验）见 [`11-转向锐度定档-AB实验.md`](11-转向锐度定档-AB实验.md)。

```bash
python tools/carswap.py \
    --swap "Aston Martin Valkyre>Chevrolet Camaro LT" --grip 0.95 \
    --swap "Mercedes_AMG_One>BMW Z4 LCI E89" \
        --top-speed 285 --accel 2.932 --nitro-drain 0.6 --steer 98900 \
    --apply

./tools/build.sh ab-steer-max --tuned ".../tuned-carswap" \
    --files CarPhysics.gdb CarChassis.gdb CarDef.gdb
```

全库百分位一律以 [`02-字段表/fleet-stats.md`](../02-字段表/fleet-stats.md) 为准。

## 调参原则（A/B 实验后确立的）

**增益只动「动力三件套 + 锐度」，侧向力链整套用供体原厂配平，不拆开抄。**

- 可动：极速 / 加速 / 氮气消耗 / **转向锐度 19/21**（几何转向能力，
  不进侧向力配平）
- 不可拆：抓地 / 下压力 / 悬挂行程 / 重心 / 操控 ——
  这五项是供体原厂互相咬合的一套，单独放大任何一项
  （grip 1.02~1.28 那两次）都会把抬轮和悬挂顶出问题。

**锐度与操控是两个独立维度**（原厂反例：Devel 锐度 98900 全库第一但
idx77 只有 0.21；塞纳锐度才 52500，idx77 却是 1.00 全库最高）：
锐度管几何转向半径（A/B 单变量实测确认，见 `11`），idx76/77 管漂移特性。
> 早前据面板相关 0.2864 推断「锐度更像转向响应速度、不管半径」——
> 已被 `ab-steer-max` 单变量实测推翻。

## 两台共有

- **满改锁**：18 对升级值全部钉在满级端（含下压力对 30/31）——
  任何星级/改装状态输出同一套性能
- 外观/碰撞/动画/特效来自供体（CarDef 带过来，没动任何资源文件）
- **引擎声保留受体自己的**；面板数字不动是铁律

## 踩过的坑（按时间）

- **微调组乱抬轮**：grip 1.02~1.28 + 重心 −0.0975~−0.122 + handling 1.0
  那两版（`amgone-z4c` / `z4-steer80k`）「乱抬轮、悬挂异常高、
  下压力压不住」。恢复原厂物理后**完全消失**——侧向力超出原厂
  下压力+行程的配平。见 [`11`](11-转向锐度定档-AB实验.md) 结论一。
- **锐度 +12% 无感**：65000 体感无变化，98900 立竿见影——
  验证变量有效性要一步跨到顶格值。
- **开屏闪退**：底盘「描述符改指向」在多车替换时被另一台触发的重排
  搞成野指针，见 [`01-代码层/07`](../01-代码层/07-底盘改指向的陷阱.md)。
  现一律复制记录体。
- **apksigner 32 位溢出**：build-tools ≤36 签不了 3.5GB 包，37.0.0 被
  卸载后构建断链。build.sh 已改为自动探测最高版本（并重装了 37.0.0）。
