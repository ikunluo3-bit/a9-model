## 2. 类型构成（428B 档）

**不是纯 float 数组。**

| 类型 | 槽位 |
|---|---|
| int64（低位有值 + 高位恒 0） | 0, 7, 17, 24, 26, 28, 62, 64, 66, 68, 83 |
| int32 | 12, 75, 88 |
| float | 其余 |

按纯 float 读 int 槽会得到 0 或天文数字——这是早期分析踩过的坑。

## 3. 语义分布

| 类别 | 数量 |
|---|---:|
| 已命名 | 38 |
| 全车常量（不区分车型） | 44 |
| **随车变化但未知** | **25** |

**那 44 个常量是引擎级默认值**——它们不造成车与车的差异，
但决定"A9 整体是什么手感"。
**那 25 个未知的才是车辆个性的来源，是主攻目标。**

## 4. 尾部可变长数组

428B 记录末尾是三对 `(0, 1000)`：

```
idx 101/102 = 0 / 1000
idx 103/104 = 0 / 1000
idx 105/106 = 0 / 1000
```

更长的记录就是在这里**追加更多同样的 `(0, 1000)` 对**：

| 记录 | 对数 |
|---|---:|
| 428B | 3 |
| 436B | 4 |
| 444B | 5 |
| 452B | 6 |

（460B / 468B 在此之前还多一段前缀：468B 为 `1,1, 0.5,0.5`）

**每项是一个 `(min, max)` 区间。** 燃油车 3 项、电动车 6 项。
具体语义未定；注意**电动车不能套用基准下标**。

### 关于 idx 2 / 3 / 4 = 1250 / 8200 / 7250

数量级与三轴转动惯量相符（roll < yaw < pitch），但**未经验证**。
若成立，则 pitch 惯量在 gdb 里是有标量的（早前认为"无独立数据库标量、
只能由 Frida 运行时写入"的判断需要复核）。**目前仅为假设。**

### 关于 idx 70 / 71 = 50 / 120

全车完全相同的一对。若单位为 m/s，则 50 → 180 km/h、120 → **432 km/h**。
塞纳改动恰好把 ground_speed 设为 120 m/s（= 432 km/h），与 idx 71 数值相同。
**但实测可跑到 600 km/h（166.7 m/s），超过该值**，所以 idx 71 不是硬性速度上限，
或者单位并非 m/s。**待查，不做结论。**
